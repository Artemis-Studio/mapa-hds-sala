## Princípios mestres (resumão para release rápido)

1. **Estrutura > palavras.** Mercados não respondem a vocabulário, respondem a sequência. (Sultanic)
2. **Buying pattern = selling pattern.** Quem você é como comprador é como você vende bem. (Sultanic)
3. **Copy é gatilho, não argumento.** A copy alimenta o monólogo interno do prospect — ele se convence sozinho. (Sultanic)
4. **Tornar visível o invisível.** A maior alavanca é nomear o medo, o custo de ficar igual, a objeção silenciosa. (Fladlien)
5. **Lista é o ativo. Copy é a força.** Alavancagem vem de relacionamento, não de retórica. (Settle, Orzechowski)
6. **Email diário não é frequência — é filtro.** Quem aguenta cadência converte; quem não, sai. (Settle)
7. **Format change > copy change.** Trocar formato de VSL/oferta converte mais que reescrever palavras. (Sultanic)
8. **Eliminar substitutos.** Modalidades distintas tornam a oferta incomparável. (Fladlien)
9. **Infotainment > info.** Entreter ou morrer. (Settle)
10. **Não imitar voz, imitar método.** Reverse engineer destrói; estudar mestres mortos amplifica. (Settle)
11. **Direct response paga. Branding amplifica.** Não trocar a base pelo verniz. (Sultanic, Fladlien)
12. **Especificidade vence generalidade.** Números, datas, nomes, cores, lugares. (princípio transversal)

## Não-fontes

Materiais que **não** entram aqui: posts genéricos de "ChatGPT prompts for copy", listas de "100 power words", swipe files sem proveniência, gurus solopreneur americanos. Só material com substância testada em mercado real.

## Ciclo de manutenção

- **Mensal:** ler `11-anti-padroes` em jejum; revisar lista de violações próprias.
- **Trimestral:** adicionar nova fonte (livro, mentor, transcrição) → ingestar → atualizar arquivos relevantes.
- **Anual:** auditar quais princípios foram aplicados na operação e quais ficaram só na teoria.
