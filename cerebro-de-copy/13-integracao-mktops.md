# 13 — Integração com MktOps

O Cérebro de Copy é a **camada estratégica** acima das skills do MktOps. Esse arquivo mapeia cada princípio para skill, ato, canal — e dá o playbook operacional.

> Skills executam. O Cérebro pensa. Os dois juntos é o produto.

## 3. Workflow canônico — peça nova de cliente

```
1. BRIEFING
   → One Page 2.0 ([[02-arquitetura-da-copy]] §11)
   → Buyer pattern do cliente ([[01-psicologia-do-prospect]] §2)
   → Nível Schwartz da audiência ([[01-psicologia-do-prospect]] §4)

2. ANÁLISE DE PROSPECT
   → As 5 portas de Blair Warren ([[01-psicologia-do-prospect]] §5)
   → 10 objeções literais + movimento por objeção ([[10-persuasao-e-objecoes]] §16)
   → Linguagem nativa (extraída de calls + reviews)

3. DESIGN DA OFERTA
   → AC Funnel ou modelo equivalente ([[08-offers-e-economia]])
   → Stack incomparável (eliminar substitutos — Fladlien)
   → Garantia + risk reversal

4. ESCOLHA DE FRAMEWORK
   → Tabela de [[02-arquitetura-da-copy]] §13 (canal × duração → framework)

5. ESCRITA — RASCUNHO 1 (porta fechada)
   → Hook ([[03-hooks-e-aberturas]])
   → Bridge ([[04-bridges-e-transicoes]])
   → Body ([[05-body-copy-frameworks]])
   → Close ([[06-closes-e-ctas]])

6. ESCRITA — RASCUNHO 2 (porta aberta)
   → Cortar 30%
   → Aplicar [[11-anti-padroes]] checklist
   → Ratio 7:1
   → Specificity ≥ 1 número/parágrafo
   → Aplicar [[09-bullets-e-tecnicas-de-frase]] §17 (checklist)

7. GATE
   → Skill [[copywriting-guardrails]]
   → Skill [[copy-format-check]] (se for ad)
   → Validação humana (o responsável ou um sênior)

8. PUBLICAÇÃO
   → Mautic / Meta Ads / LinkedIn / Instagram / Substack
   → Tag KPI no dashboard

9. FEEDBACK LOOP
   → Open rate / CTR / conversão
   → Iterar a peça menos performada da semana
```

## 4. Mapa por cliente — qual fluxo aplicar

### MktOps (produto-mãe)
- **Carrossel Instagram**: `carousel-mktops` modo CASO ou MEC
- **Email**: `email-sequence` Settle-style 7×/semana
- **VSL**: `vsl-writer` modo longa para lançamento
- **Substack (Notas de IA)**: `substack-hbr-writer`
- **Closes preferidos**: After Close + No Choice + Identity (Identity Hard)
- **Bridges**: factual ("o ponto é o seguinte:")

### A operação de SEO da casa (SaaS)
- **Carrossel**: modo MEC com screenshot do produto
- **Email**: 5×/semana broadcast + autoresponder de 14
- **Ad estático**: AIDA + 60-Sec Hook do user case
- **Closes**: Sultanic Master compacto + Number proof

### Proteção veicular
- **Ad estático**: Eulogy opening + Specific number proof
- **VSL curta**: 60-Sec Hook + close direto
- **Email**: 4×/semana com casos reais
- **Closes**: After Close + Identity

### Rastreamento veicular (B2B telematics)
- **Cold email**: HBM + CFO-friendly briefing pronto
- **Landing**: Sultanic Master compacto + China Concierge (objeção CFO)
- **VSL média**: PASTOR + ROI quantificado
- **Closes**: No Choice + Number proof

### Telemetria náutica
- **Carrossel**: identidade + Toward
- **VSL curta**: Hero's Journey curta + Inviting Close
- **Email**: 3×/semana + autoresponder

### Conectividade IoT (chip B2B)
- **Cold email**: Number proof + CRO Doubt
- **Landing**: PAS + chunking de custo + screenshot
- **Closes**: Sultanic Master + performance-based guarantee

### SaaS de WhatsApp
- **Carrossel**: Two Types + identity stack (operador anti-volume)
- **VSL média**: PASTOR + identity
- **Email**: 5×/semana autoresponder de 28 + broadcast
- **Closes**: Identity + Two Types + 10% Close

### Clínica de estética
- **Carrossel**: 60-Sec Hook + Inviting + identity Toward
- **Ad estático**: From-To + autocuidado
- **Email**: 4×/semana
- **Closes**: Inviting + Identity Toward

### Comércio exterior
- **Cold email**: Number + Sultanic Master
- **Landing**: factual + dado de mercado
- **Closes**: No Choice + Number proof

### Governança e sucessão
- **Substack**: HBR style com case histórico de família empresária
- **Landing**: Hero's Journey (família) + autoridade FDC/IBGC
- **Closes**: Identity (legado) + Hero

### Consultoria de carreira
- **Carrossel**: 60-Sec Hook + Hero's Journey curta
- **Email**: autoresponder + broadcast
- **Closes**: Identity + Inviting

## 6. Como o Cérebro evolui

### Inputs novos
Todo trimestre, adicionar 1 fonte canônica (autor, livro, transcrição). Atualizar arquivos relevantes.

### Outputs medidos
Auditar mensalmente quais princípios foram aplicados na operação real e quais ficaram só na teoria. Os não-aplicados:
- Não funcionam pra nossa realidade → **mover para 9-Archive**
- Funcionam mas falta disciplina → **highlight no daily brief** até virar prática

### Retroalimentação
Quando uma campanha bate ou destrói o controle, **destilar o porquê** e atualizar o arquivo correspondente do Cérebro com o aprendizado.
