# 05 — Body Copy Frameworks

Depois do hook e do bridge, vem o corpo: o argumento que constrói desejo até o close. Este arquivo é o conjunto de esqueletos para esse corpo.

---

## 1. Lei mestre do body copy

Body copy não convence. Body copy **alimenta o monólogo interno do prospect** com material para ele se convencer sozinho. Cada parágrafo deposita uma pedrinha do lado da compra na balança (Orzechowski).

Operação básica:
1. Construir frame ("você está vivendo X")
2. Quebrar frame ("e X é o problema, não a solução")
3. Reconstruir frame maior ("a verdadeira solução é Y, e ela funciona assim")
4. Provar Y com caso, dado, mecanismo
5. Antecipar objeção ("você deve estar pensando Z, mas...")
6. Desire stack até identidade

---

## 2. PAS — o framework mínimo

```
PROBLEM   → o problema do prospect
AGITATE   → amplificar a dor; tornar visível o invisível
SOLVE     → apresentar a solução
```

Quando usar: ad curto, email diário, lead magnet, retargeting.

**Variação Fladlien (double bind)**: o A não é só amplificar dor presente — é **projetar** a dor 5/10/20 anos no futuro. Custo de ficar igual.

---

## 3. PASTOR — o framework expandido

```
P  PROBLEM       → identificar o problema
A  AMPLIFY       → amplificar custo emocional + financeiro + temporal
S  STORY         → contar uma história relacionável (sua ou de cliente)
T  TRANSFORM     → mostrar o mecanismo de transformação
O  OFFER         → apresentar oferta concreta
R  RESPONSE      → CTA + urgência
```

Quando usar: VSL média (3-7min), email longo, carta de venda média.

---

## 4. AIDA — o clássico

```
ATTENTION  → capturar atenção
INTEREST   → manter via promessa específica
DESIRE     → desire stack até identidade
ACTION     → CTA
```

Quando usar: ad gráfico, headline + sub, copy curta para retargeting.

---

## 5. Estrutura-Mestre Sultanic — VSL e sales letter de alta performance

Já formulada em [[02-arquitetura-da-copy]]. Recapitulando para uso no body:

```
1. DICOTOMIA → 2 grupos, prospect no errado
2. INVALIDAÇÃO → "It has nothing to do with..."
3. MECANISMO → "It has everything to do with..."
4. CREDIBILIDADE → caso pessoal ou de cliente
5. PROMISE → "in the next 7 minutes..."
6. PAYOFF CHAIN → funcional → liberdade → identidade
7. CLOSE POR ELIMINAÇÃO
```

Quando usar: VSL longa, sales letter, página premium, lançamento.

---

## 6. Hero's Journey aplicada (Campbell via Sultanic)

```
1. PROTAGONISTA RELATÁVEL
2. CHAMADO À AVENTURA (problema/desejo)
3. RECUSA / TENTATIVA FALHADA
4. ENCONTRO COM O MECANISMO
5. JORNADA DE PROVA
6. RETORNO TRANSFORMADO
7. CONVITE AO LEITOR
```

Quando usar: VSL longa, lançamento de produto, conteúdo de marca, livro como sales letter.

> "Um livro bem escrito é a melhor sales letter que existe." — Fladlien

---

## 7. Persona Joke Formula (Rogers) — body para conteúdo de marca

```
1. IDENTITY → 2. STRUGGLE → 3. DISCOVERY → 4. SURPRISE
```

Para conteúdo (não venda direta). Punchline em vez de result. Aplicar em: post pessoal, intro de webinar, primeira fala de Reels orgânico.

## 8. Body por nível de consciência (Schwartz)

Cada nível pede body diferente:

### Nível 1 — Inconsciente
Body educativo. Conta história. Mostra problema. **Não vende.**
- Padrão: HBM (Hook-Bridge-Message) sem oferta direta
- Objetivo: levar o prospect ao nível 2

### Nível 2 — Consciente do problema
Body agitador. Mostra o quanto dói. Custo de ficar igual.
- Padrão: PAS expandido (custo em 1, 5, 10 anos)
- Objetivo: levar ao nível 3 (apresentar solução)

### Nível 3 — Consciente da solução
Body de mecanismo. Como sua solução funciona. Por que funciona.
- Padrão: Hero's Journey + chunking
- Objetivo: levar ao nível 4 (consciente do produto)

### Nível 4 — Consciente do produto
Body de diferenciação. Por que você ≠ concorrente. Prova.
- Padrão: Sultanic Master compacto + comparação
- Objetivo: nível 5 (oferta)

### Nível 5 — Consciente da oferta
Body curto. CTA direto + urgência + garantia.
- Padrão: Stack de oferta + close direto
- Objetivo: clique

## 9. Modos do MktOps — 3 estruturas de body

Da skill [[carousel-mktops]]:

### Modo CASO (12 slides)
Narrativa de personagem real. Os 4 atos completos.
```
NARRATIVA → PRINCÍPIO → APLICAÇÃO → OFERTA
```
Body do Ato 1 carrega o personagem. Ato 2 extrai o princípio. Ato 3 mostra aplicação. Ato 4 fecha.

### Modo MEC (10 slides)
Mecanismo próprio com screenshot-prova. Body é mais técnico.
```
NARRATIVA (1) → MECANISMO (5 com screenshots) → APLICAÇÃO (2) → OFERTA (2)
```

### Modo DESTILADO (10 slides)
Comentário editorial sobre insumo curado. Body é análise.
```
NARRATIVA (1) → DESTILAÇÃO (5) → APLICAÇÃO (2) → OFERTA (2)
```

## 10. Estruturas de fechamento de cada bloco do body

Cada parágrafo do body precisa **vender o próximo**. Padrões:

### Promessa de payoff próximo
> "E aí vem a parte mais importante."
> "Em 30 segundos vou te mostrar como."

### Cliffhanger
> "E quando ele me contou o que fez, eu não acreditei. Volto pra isso já já."

### Inserção de objeção (CRO Doubt)
> "Você deve estar pensando: 'isso não se aplica a mim'. Espere."

### Ancoragem temporal
> "Isso aconteceu em 11 minutos. E é exatamente o que vou te mostrar."

## 11. As 4 técnicas centrais que rodam DENTRO do body

### A. Frame stacking
Construir frame → quebrar → reconstruir maior. (Sultanic — ver [[02-arquitetura-da-copy]])

### B. Chunking
Quebrar claim grande em pedaços plausíveis. Cada chunk aceito reduz resistência ao próximo.

### C. CRO Doubt Insertion
Inserir a objeção do prospect ANTES que ele a pense.

### D. External Blame / Not Your Fault
Remover culpa do prospect, colocar em fator externo.

> "And it has nothing to do with your [esforço]... It has everything to do with [external thing]."

---

## 12. Desire Stacking dentro do body

Empilhar desejo em cadeia, do funcional ao identitário:

```
1. Funcional ("você fecha 3 clientes/mês")
2. Emocional ("você acorda com agenda cheia, sem ansiedade")
3. Identidade ("você é o operador que parou de implorar")
4. Vida futura ("em 12 meses, você não trabalha à noite")
```

Cada camada **intensifica** a anterior. Não pular para identitário sem ancorar funcional. Quem pula soa hipster.

## 13. Inserção de prova — onde e como

| Tipo de prova | Onde colocar | Formato |
|---|---|---|
| **Case study completo** | Centro do body | Antes/depois com nome, número, data |
| **Number proof** | No meio do argumento | "47 clientes em 90 dias" — específico |
| **Authority endorsement** | Depois do mecanismo | Quote curta + foto + nome |
| **Screenshot / printscreen** | Junto a claim técnica | Visual, com legenda |
| **Social proof scrolling** | Antes da oferta | 3-5 testemunhos curtos |
| **External validation** | Antes do close | Citação de mídia, pesquisa, autoridade |

> Princípio Sultanic: prova **por contraste, não por argumento**. Mostrar dois personagens, deixar contraste fazer o trabalho.

---

## 14. China Concierge pattern (Fladlien) — converter objeção em moat

Estrutura para body que neutraliza objeção difícil:

1. Reconhecer a objeção literal ("você precisa ir à China")
2. Reframe: "você precisa que **alguém** vá — não você"
3. Apresentar solução-pivô que mata a objeção
4. Mostrar como a solução é ativo, não custo

Função no body: mover de "comparável desfavoravelmente" para "incomparável".

---

## 15. Eliminar substitutos (Fladlien) — body de oferta complexa

Quando a oferta tem múltiplos componentes (ver [[08-offers-e-economia]]):

```
1. Listar TODOS os entregáveis
2. Justificar cada um pelo modo distinto (PDF + áudio + vídeo + checklist + SOP + DFY)
3. Mostrar que não é redundância — é complementaridade
4. Stackear até "incomparável"
```

> "Nunca vi nada assim na vida. As coisas parecidas custam mais e entregam menos."

---

## 16. Estrutura interna de cada parágrafo

> "Treat everything you write like it's sales copy." — Settle

- Frase curta abre
- Detalhe sensorial concreto
- Frase de tensão ou contraste
- Quebra de linha antes do ponto crítico

```
Não:
"Como copywriter sei que é difícil escrever bem, mas com prática você melhora e..."

Sim:
Escrever copy boa é difícil.

Você senta na cadeira.
Encara a tela.
Nada vem.

E aí lembra de uma coisa que o Halbert disse há 50 anos:
'Just write the damn letter.'

Funciona.
"
```

Ritmo > polidez. Espaçamento > parágrafo cheio.

| Canal | Duração | Pattern |
|---|---|---|
| Reels/Shorts | 30-60s | 60-Sec Hook + 1 chunk + close |
| Carrossel Instagram | 8-12 slides | MktOps 4 Atos |

| Email de venda | 600-1200 palavras | PAS + Hero compactada |
| VSL curta | 200 palavras | 60-Sec Hook + 1 chunk + close direto |
| VSL média | 1000 palavras | PASTOR ou Sultanic Master compacto |
| VSL longa | 3000-4000 palavras | Sultanic Master + Hero's Journey + 3 cases |
| Landing premium | 2000-5000 palavras | Sultanic Master + comparação + China Concierge se necessário |
| Substack HBR | 1500-3000 palavras | Situation-Complication-Resolution + 2 dados frescos |
| Sales letter direct mail | 4000-8000 palavras | Sultanic Master + Hero's Journey + 5 cases + 3 garantias + P.S. |
